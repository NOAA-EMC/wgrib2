Detailed Description

Unit Conversion Factors.

PURPOSE: This function determines the conversion factor between the input unit type and the output unit type. Valid types include:

  • 0 = Radians
  • 1 = U.S. feet
  • 2 = Meters
  • 3 = Seconds of arc
  • 4 = Degrees of arc
  • 5 = International feet
