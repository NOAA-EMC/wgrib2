int f_set_ensm_derived_fcst ( ARG2  )

Changes Product Definition Template (PDT) 0,1,2 -> 2 or 8,11,12 -> 12.

PDT 2, and 12 are for "ensemble mean derived forecasts". Effectively this options describes the forecast as being derived from an ensemble of forecasts. The types derived forecasts is listed in code table 4.7. The "cluster" derived forecast should not be used with this option as PDT 2 and 12 do not have metadata to describe the cluster that was used.

-set_ensm_derived_fcst X Y

X = code table 4.7.

Y = 0..255 number of forecasts in the ensemble

Parameters
ARG2List of function arguments set by wgrib2's main() function (see ARG2). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 for success, error code otherwise
