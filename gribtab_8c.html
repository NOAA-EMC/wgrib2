Detailed Description

GRIB table definitions for various meteorological centers.

Now have two types of grib table:

Primary has the names for WMO defined variables has the names for its locally defined variables as of 1/2021, only ncep and ecmwf can be primary

Secondary has the names for its locally defined variables The WMO defined variables are specified by the primary grib tables
