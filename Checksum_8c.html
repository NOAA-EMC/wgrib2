Detailed Description

Calculate CRC32 checksum for sections and the whole message.

The checksum algorithm is the same as the POSIX 'cksum' utility uses.

int f_checksum ( ARG1  )

Writes the checksum (32 bit CRC) for the entire grib message, the decoded grid-point data or any specified section.

-checksum N

Where N is: -1: whole message 1-8: section number data: grid-point data

Parameters
ARG1List of function arguments set by wgrib2's main() function (see ARG1). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 for success, error code otherwise.
Note
Two sections or messages with the same checksum are very probably the same. If the grid-point data has the same checksum, they are very probably bitwise identical. This option can be used to check the integrity of a grib message or to check for for identical sections. Note that decoded grid-point values may not be unique. Wgrib2 is compiled with the "fast" option which may sacrifice some precision for speed or uniqueness. For example, A*B*C should be calculated by (A*B)*C. However A*(B*C) will be faster if B*C was previously calculated. While mathematically the expressions are the same, the final results may be slightly different.
