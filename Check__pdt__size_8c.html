int f_check_pdt_size ( ARG1  )

Function to set the check_pdt_size_flag.

If the PDT is wrong size, wgrib2 will exit with a delayed fatal error. The fatal error is delayed so the user can investigate the contents of the bad grib message. Note that it is possible to seg fault because Section 4 is a different size than expected, and the rest of the grib message may be corrupted.

You may skip this check by using the -check_pdt_size 0 option.

-check_pdt_size X

Where X is 0 (disable) or 1 (enable, default).

Parameters
ARG1List of function arguments set by wgrib2's main() function (see ARG1). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 for success.
Note
In theory, the pdt can be bigger than expected with no ill consequences, however, if the pdt is smaller than expectations, then any routine that uses the pdt could be reading outside of the pdt.
