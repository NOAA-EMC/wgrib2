◆ g2nc_conv

struct g2nc_conv

User defined table of GRIB2 to NETCDF conversion parameters.

It would be read from user file provided with '-nc_table' option.

Format: wgrib2_name:[wgrib2_level|*]:nc_name[:[short|byte]:min:max]

wgrib2_name, wgrib2_level are as returned by wgrib2 in inventory;

'*' used as wgrib2_level will apply for all levels not given explicitly, packing information is optional but it overwrites common packing if given with the '-nc_pack' option. Absence of packing info means no packing. Both zero min and max values activate 'auto' packing when these values are defined from the first entered field. When packing, fitting is checked, error if do not fit.
