◆ f_wind_uv()

int f_wind_uv ( ARG1  )

Takes the wind speed and wind direction, computes the zonal (UGRD) and meridional (VGRD) wind components, then writes out the wind components in grib format.

If the wind direction is earth (grid) relative, the UGRD and VGRD winds are earth (grid) relative.

You can save computer time by using the -match option to restricting the decoding of records to wind speed (WIND) and wind direction (WDIR).

-wind_uv output_grib_file

Parameters
ARG1List of function arguments set by wgrib2's main() function (see ARG1). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 on success. Throws fatal_error() on failure.
