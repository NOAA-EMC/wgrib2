Detailed Description

Find nearest-neighbor grid point for a given latitude/longitude.

Based on algorithms from: LRIT/HRIT Global Specification, Coordination Group for Meteorological Satellites Doc No CGMS 03 isssue 2.6 Date - 12 August 1999

This document assumed certain constants: satellite height radius (pole/equator) which differed from the values in the grib file. I attempted to replace the constants with the grib-specified values.

I used a different test to see if the grid point is visible than suggested by the code MSG_navigation_v1.01.c by EUMETSAT.
