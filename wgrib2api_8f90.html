Parameters
[in]grbfileName of the grib file to write.
[in]template_fileName of the grib file that is used as a template for the new grib file.
[in]template_idID of the template to use.
[in]data1Optional 1D array of real numbers (grid data). Must be specified if data2 is not.
[in]data2Optional 2D array of real numbers (grid data). Must be specified if data1 is not.
[in]packingPacking type (optional). Used with -set_grib_type option to control the packing method of the new grib message. If packing is not specified, the default packing method will be used (c2).
[in]orderOrder of the data (optional). Used with -order option to specify the order of the data. The default configuration is for wgrib2 to convert all data into 'we:sn' order. If order = 'raw', fastest data must be in same order as the template. If order = 'we:ns', data must be in 'we:ns' order. If order = 'we:sn', data must be in 'we:sn' order.
[in]varVariable name (optional). Used with -set_var option to change the variable name in the grib message.
[in]metaString to specify the metadata (optional). Used with -set_metadata_str option to apply the metadata to the grib message.
[in]appendFlag to append to output files (optional). If non-zero, the -append option is applied to append to a currently existing file.
[in]levelString representation of the level/layer of the field (optional). Used with -set_lev option to change the level/layer of the field in the grib message.
[in]dateReference date (optional). Used with -set_date option to change the reference date in the grib message.
[in]timingString representation of ftime (optional). Used with -set_ftime2 option to change the ftime in the grib message.

[in]fhour_ave1Forecast hour average 1 (optional). Used with fhour_ave2 and -set_ave option to change the ftime in the grib message. This option was used with version 1 of ftime which will be removed in future releases.
[in]fhour_ave2Forecast hour average 2 (optional). Used with fhour_ave1 and -set_ave option to change the ftime in the grib message. This option was used with version 1 of ftime which will be removed in future releases.
[in]fhour_acc1Forecast hour accumulation 1 (optional). Used with fhour_acc2 and -set_ave option to change the ftime in the grib message. This option was used with version 1 of ftime which will be removed in future releases.
[in]fhour_acc2Forecast hour accumulation 2 (optional). Used with fhour_acc1 and -set_ave option to change the ftime in the grib message. This option was used with version 1 of ftime which will be removed in future releases.
[in]centerCenter ID (optional). Used with -set center option to change the center ID in the grib message.
[in]subcenterSubcenter ID (optional). Used with -set subcenter option to change the subcenter ID in the grib message.
[in]mbReal value of level of the field (optional). Used with -set_lev option to change the level in the grib message.
[in]debugDebug flag (optional).
[in]encode_bitsNumber of bits(optional). Used with -set_bin_prec option to change number of bits to encode grid point data in the grib message.
