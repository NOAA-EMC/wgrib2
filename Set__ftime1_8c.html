◆ f_set_ftime1()

int f_set_ftime1 ( ARG1  )

Calls the old routines to set forecast time stamp.

With wgrib2 v2.0.7, routines for generating started to shift from -ftime1 to -ftime2. Since wgrib2 needs the ability to read the time stamps, the routines that wrote the time stamps also had to shift from from -set_ftime1/-set_ave -> -set_ftime2.

One should not use this option because the old ftime routines could not handle more complicated time stamps and needed a rewrite (ftime2 routines).

-set_ftime1 X

X = 'N hour fcst'

Parameters
ARG1List of function arguments set by wgrib2's main() function (see ARG1). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 on success. Throws fatal_error() on failure.
