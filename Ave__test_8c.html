Detailed Description

This file contains the implementation of the -ave0 option and some helper functions.

The -ave0 option is the old (v2.0.6) version of the -ave option.

◆ f_ave0()

int f_ave0 ( ARG2  )

Calculates temporal averages of grib data and writes the results to a specified output file.

This is the old version (v2.0.6) of the -ave option.

-ave0 (time interval) (output grib file)

The time interval is the delta time for averaging (e.g., "6hr", "1dy").

Parameters
ARG2List of function arguments set by wgrib2's main() function (see ARG2). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 for success, error code otherwise.
