This routine takes the grib section and makes a g2lib igdtmpl(*) array for ipolates2 library.

igdt is used by NCEP grib and ipolates2 libraries.

Parameters
secPointer to the GRIB2 message sections. Only sec[3][*] is used.
igdtnumPointer to output grid definition template number.
igdttmplPointer to output grid definition template array.
igdtleniPointer to output grid definition template length.

0 on success, error code otherwise
