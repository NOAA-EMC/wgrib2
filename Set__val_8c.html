int f_set_ijval ( ARG3  )

Sets one grid point value of the decoded grid.

After changing the grid value, one usually writes out the grid using -grib_out FILE. The -set_ijval option only works when the grid is a rectangular array. For example, staggered and thinned grids are not stored an an array.

-set_ijval I J VAL

grid(I,J) = VAL I = 1 to NX J = 1 to NY

Parameters
ARG3List of function arguments set by wgrib2's main() function (see ARG3). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 on success. Throws fatal_error() on failure.

◆ f_set_ival()

int f_set_ival ( ARG2  )

Sets one or more grid point values of the decoded grid.

After changing the grid value, one usually writes out the grid using -grib_out FILE.

-set_ival I VAL -set_ival I1:I2:..:In VAL1:VAL2:..:VALn

I, I1, .. In is the grid point from 1 to npnts VAL, VAL1, .. VALn are floating point values

Parameters
ARG3List of function arguments set by wgrib2's main() function (see ARG3). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 on success. Throws fatal_error() on failure.
