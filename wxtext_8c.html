int mk_WxKeys ( unsigned char **  sec)

NDFD uses section 2 (local) to keep weather information keys.

These keys are text strings with weather info. This function decodes and makes a copy of the keys.

Parameters
secPointer to the GRIB sections.
Returns
0 on success. Throws fatal_error() on failure.
