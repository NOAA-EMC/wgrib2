Create the grib2 Section 3 (GDT Section) for straight forward gaussian grid.

GRIB2 allows regional and thinned gaussian grids. This routine only allows global gaussian grids.

Parameters
nxNumber of grid points in the x-direction.
x0Starting longitude.
dxLongitude increment.
nyNumber of grid points in the y-direction.
y0Starting latitude.
dyLatitude increment.
old_secPointer to old section data (if available).
Returns
Pointer to the new section 3 data.
