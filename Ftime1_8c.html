Detailed Description

Implementation for -ftime1 and helper functions.

The -ftime1 option is the older version of -ftime2 and will be removed in future releases.

◆ f_ftime1()

int f_ftime1 ( ARG0  )

Prints the forecast time stamp.

This is the old version of this routine and has since been replaced by the -ftime2 routine because -ftime1 could not handle more complicated time stamps correctly. One should not use -ftime1. The -ftime2 routines will work with more complicated time stamps and are more powerful.

This option will be removed in future releases.

-ftime1

Parameters
ARG0List of function arguments set by wgrib2's main() function (see ARG0). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 for success, error code otherwise
