◆ f_set_radius()

int f_set_radius ( ARG1  )

Sets the shape and size of Earth according to Code Table 3.2.

The geolocation of the grid points is done prior to the execution of the run-time options. So the -set_radius will not affect calculations of the lat-lon of the grid points. To get the correction locations after using the -set_radius option, you must write the file with the new shape of the Earth. Then you can use this new file.

-set_radius N N=0,2,4,5,6,8,9 Code Table 3.2 is set to N

-set_radius 1:R R=radius in meters (spherical) Code Table 3.2 is set to 1

-set_radius 3:X:Y X=major axis Y=minor axis (oblate spheroid), X, Y in km Code Table 3.2 is set to 3

-set_radius 7:X:Y X=major axis Y=minor axis (oblate spheroid), X, Y in m Code Table 3.2 is set to 7

Parameters
ARG1List of function arguments set by wgrib2's main() function (see ARG1). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 on success, error code otherwise.
