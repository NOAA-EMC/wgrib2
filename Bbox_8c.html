◆ f_ijbox()

int f_ijbox ( ARG4  )

Takes a rectangular box of data from a rectangular grid and writes it out in either text, bin, or spread (sheet) format.

The extracted box can have every point or every n-th point.

-ijbox i1:i2:di j1:j2:dj output_file format

i1:i2:di specifies the x-dimension, where i1 is the starting index, i2 is the ending index, and di is the increment. j1:j2:dj specifies the y-dimension, where j1 is the starting index, j2 is the ending index, and dj is the increment. output_file is written in the specified format (e.g., "bin", "text", "spread").

Parameters
ARG4List of function arguments set by wgrib2's main() function (see ARG4). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 for success, error code otherwise.
