Detailed Description

Routine to write grib files for C API.

This is part of c_wgrib2api: grb2_wrt(...)

To support a variable number of search strings, C99 is required: VA_ARGS To use a C compiler that doesn't support this C99 feature 1) remove "#define grb2_wrt(...) grb2_wrtVA(__VA_ARGS__, NULL)" from c_wgrib2api.h 2) Change calls to grb2_wrt(...) to grb2_wrtVA(...,NULL) The call code to grb2_wrtVA() will work in C99 systems.
