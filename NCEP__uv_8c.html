int f_ncep_uv ( ARG1  )

Combine U and V fields into one message like NCEP operations.

Operational NCEP grib files often have the U and corresponding V fields in the same grib message. (U and V are submessages.) Typically wgrib2 converts all the submessages into individual messages. In order to combine the U and V fields together, you replace the -grib option with -ncep_uv. Options like -grib_out and -new_grid do not have the capability to combine the U and V fields. For theses cases, you run the output through wgrib2. Note that -ncep_uv is more like -grib than -grib_out. The option -ncep_uv uses the compressed grid point values from the original file. Neither the grid point values nor the packing is changed.

-ncep_uv FILE

Parameters
ARG1List of function arguments set by wgrib2's main() function (see ARG1). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 for success, error code otherwise
