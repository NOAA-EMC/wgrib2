int f_set_prob ( ARG5  )

Converts some common non-probability Product Definition Template (PDT) to a probability PDT.

Then it adds the metadata for the probability part of the PDT.

If current PDT is 0,1,2,3,4 or 6, then the PDT is converted to 6 (4.6) using the -set_pdt +5 option.

If current PDT is 8,10,11,12,13,14 or 15, the he PDT is converted to 9 (4.9) using the -set_pdt +9 option.

If the current PDT does not have Code Table 4.9 entry, print a warning and return.

Fill in the various probability metadata using arguments to the option.

-set_prob X Y Z A B

X = forecast probability number Y = total number of forecast probabilities Z = probability type (see Code Table 4.9) A = lower limit B = upper limit

X, Y, Z, A, or B can have the value "". When the value "" is used, the previous value is not changed.

Parameters
ARG5List of function arguments set by wgrib2's main() function (see ARG5). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 on success. Throws fatal_error() on failure.
