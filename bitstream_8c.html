int  offset,
int *  u,
int  n_bits,
unsigned int  n

Reads a bitstream and converts it to an array of unsigned integers.

The function assumes that the bitstream starts on a byte boundary. For 32-bit machines, n_bits should be less than or equal to 25.

bitstream (n_bits/uint) -> u[0..n-1]
