int f_ftn_api_fn0 ( ARG0  )

Returns often needed information about a grib message.

This option is used by the grb2_inq function in the ftn_api for reading grib. Since the ftn_api and wgrib2 are part of the same package, there is no need for compatibility between versions of wgrib2. Use of this option is not recommended. The current output is by this C statement:

sprintf(inv_out, "%8d %8u %8u %8u %8d %8d",inv_no,npnts,nx_,ny_,msg_no, submsg)

Parameters
ARG0List of function arguments set by wgrib2's main() function (see ARG0). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 on success
