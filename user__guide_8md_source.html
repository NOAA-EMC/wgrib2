3 # Introduction
4 
5 This document briefly describes wgrib2, a utility and library for
6 interacting with, reading, writing, and manipulating GRIB2 files.
7 
8 Wgrib2 is maintained as a collaboration between [Climate Prediction
9 Center (CPC)](https://www.cpc.ncep.noaa.gov/) and the [Environmental
10 Modeling Center (EMC)](https://www.emc.ncep.noaa.gov/emc.php).
11 
12 ## Installation
13 
14 Download the tarball from the release page and unpack it, and cd into the main directory of the library. Then run the following commands, substituting your directory locations for the CMAKE_INSTALL_PREFIX (where wgrib2 will be installed), and the CMAKE_PREFIX_PATH (where the build will look for dependencies):
15 
16 ```
17 mkdir build && cd build
18 cmake .. -DCMAKE_INSTALL_PREFIX=install -DCMAKE_PREFIX_PATH="/usr/local/NCEPLIBS-g2c;/usr/local/NCEPLIBS-ip" <Additional CMake options>
19 make
20 make install
21 ```
22 
23 Additional CMake build options can be used to configure the build by setting them with `-D<OPTION>=<VALUE>`.
24 
25 ### Common CMake Options
26 
27 | Option | Description | Default | Additional Requirements |
28 |--------|-------------|---------|-------------------------|
29 | BUILD_LIB | Build wgrib2 library | ON | N/A |
30 | BUILD_SHARED_LIB | Build wgrib2 library as a shared library | ON | N/A |
31 | MAKE_FTN_API | Build Fortran API | OFF | BUILD_LIB = ON |
32 | USE_NETCDF | Read and write NetCDF files | OFF | NetCDF-c |
33 | USE_IPOLATES | Use NCEPLIBS-ip library (required for grid interpolation) | OFF | [NCEPLIBS-ip v5.2.0+](https://github.com/NOAA-EMC/NCEPLIBS-ip) |
34 | USE_G2CLIB_HIGH | Use NCEPLIBS-g2c high-level decoder (needed for '-g2clib 2' option) | OFF | [NCEPLIBS-g2c 2.2.0+](https://github.com/NOAA-EMC/NCEPLIBS-g2c) |
35 | USE_G2CLIB_LOW | Use NCEPLIBS-g2c low-level decoders for PNG (packing type 41) and Jpeg2000 (packing type 40) | OFF | [NCEPLIBS-g2c 2.2.0+](https://github.com/NOAA-EMC/NCEPLIBS-g2c) with desired decoders enabled |
36 | USE_AEC | Use AEC to enable encoding/decoding of GRIB2 data with CCSDS packing (packing type 42) | OFF | [libaec v1.0.6+](https://gitlab.dkrz.de/k202009/libaec) |
37 | USE_OPENMP | Use with OpenMP | OFF | OpenMP-c |
38 | USE_PROJ4 | Use with Proj.4 library | OFF | N/A |
39 | USE_REGEX | Enable regular expression matching options | ON | Regex Library (may be unavailable on non-POSIX systems) |

41 ### Less Common CMake and CTest Options
42 
43 | Option | Description | Default |
44 |--------|-------------|---------|
45 | CMAKE_INSTALL_PREFIX | Installation path | /usr/local |
46 | ENABLE_DOCS | Enable generation of doxygen-based documentation | OFF |
47 | BUILD_WGRIB | Build original wgrib code for GRIB1. This code is no longer supported - use at your own risk. | OFF |
48 | FTP_TEST_FILES | Fetch and test with files on FTP site. | OFF |
49 | FTP_LARGE_TEST_FILES | Fetch and test with very large files on FTP site. | OFF |
50 | FTP_EXTRA_TEST_FILES | Test with more large files fetched via FTP. | OFF |
51 | USE_TIGGE | Enable use of TIGGE gribtables | ON |
52 | USE_UDF | Enable User-Defined functions | OFF |
53 | USE_WMO_VALIDATION | Use WMO Validation Tables (unofficial templates) | OFF |
54 | DISABLE_ALARM | Disable alarm for non-compatible systems | OFF |
55 | DISABLE_STAT | Disable POSIX feature | OFF |
56 | BUILD_EXTRA | Build user-contributed code. This code is no longer supported - use at your own risk. | OFF |
57 | USE_MYSQL | Use with BUILD_EXTRA = ON to enable user-contributed MySQL options. It is user's responsibility to ensure MySQL is available. | OFF |
