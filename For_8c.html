Detailed Description

For loop processing for wgrib2 options.

The -for option allows you to set up a for-loop for records to process.

For example, to only process the first 100 records:

-for 1:100

◆ f_for()

int f_for ( ARG1  )

Selects the range of record numbers upon which to operate using the "for" syntax.

If you want to operate on records 10 to 20, you would use the parameter 10:20. If you want to operate on all the even records from 10 to 20, you would use 10:20:2. The restrictions are the start value must be less than the ending value and the step has to be greater than zero.

The -for option ignores the submessage number when selecting the fields.

-for I:J:K same as for n = I to J by K -for I:J same as for n = I to J by 1 -for I::K same as for n = I to MAX_INTEGER by K -for I same as for n = I to MAX_INTEGER by 1

Parameters
ARG1List of function arguments set by wgrib2's main() function (see ARG1). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 for success, error code otherwise
