int unpk_grib ( unsigned char **  sec,
float *  data 
)

Unpack GRIB messages based on Data Representation Template (Code Table 5.0).

Only some formats are supported:

  • 0 (simple)
  • 4 (ieee)
  • 40 (jpeg)
  • 41 (png)
  • 42 (aec)
Parameters
secPointer to the GRIB message sections.
dataPointer to the output data array.
Returns
0 on success, 1 for unsupported packing type. Throws a fatal_error() on failure.
