◆ gauss2lats()

double* gauss2lats ( int  nlat,
double *  ylat 
)

Get Gaussian latitudes.

Code for computing Gaussian latitudes was adapted from the wonderful gauss2lats.m Matlab program from Tom Holt. The code gauss2lats.m also works quite well with Octave.

Note that the algorithms used here require a 1-based array vice the typical 0-based array. The points are mapped correctly to the (lat,lon) arrays as zero-based.

Parameters
nlatNumber of latitudes.
ylatPointer to the latitude array.
Returns
Pointer to the updated latitude array.
Note
Adapted from an NCAR fortran program by Tom Holt.
