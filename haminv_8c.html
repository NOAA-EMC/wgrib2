Detailed Description

Hammer - Inverse Transformation.

PURPOSE: Transforms input Easting and Northing to longitude and latitude for the Hammer projection. The Easting and Northing must be in meters. The longitude and latitude values will be returned in radians.

This function was adapted from the Hammer projection code (FORTRAN) in the General Cartographic Transformation Package software which is available from the U.S. Geological Survey National Mapping Division.
