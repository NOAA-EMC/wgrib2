Detailed Description

Contains wgrib2 routine.

Originally the main of the wgrib2 utility. Later became main or routine depending on CALLABLE_WGRIB2. Finally, wgrib2 utility became a wrapper that calls the wgrib2 routine.

Date Programmer Comments
2005 W. Ebisuzaki Initial
1/2007 M. Schwarb unsigned int ndata
2/2008 W. Ebisuzaki add -if support
2/2008 W. Ebisuzaki fixed bug in processing of submessages
2/2025 W. Ebisuzaki previously could be main() or wgrib2(). Now only wgrib2()

the main() version became wgrib2_main.c
