Detailed Description

Computes the mean and variance using the Welford method (one-pass): http://jonisalonen.com/2013/deriving-welfords-method-for-computing-variance/.

Based on Ave_test.c

Note
variance(samples): M := 0 S := 0 for k from 1 to N: x := samples[k] oldM := M M := M + (x-M)/k S := S + (x-M)*(x-oldM) return S/(N-1)

◆ f_ave_var()

int f_ave_var ( ARG2  )

Computes the mean, standard deviation, minimum, and maximum for each grid point and writes the results to a specified output file.

The options and expected sequence of fields is the same as with the -ave option.

-ave_var (time interval) (output grib file)

The time interval is the delta time for averaging in the form (integer)(units) (e.g., "6hr", "1dy"). Units are hr, dy, mo, yr.

Parameters
ARG2List of function arguments set by wgrib2's main() function (see ARG2). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 for success, error code otherwise.
Note
Welford's method for computing the mean and variance was used because it is a one-pass scheme with the accuracy of a two-pass algorithm.
