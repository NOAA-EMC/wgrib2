◆ f_grib_ieee()

int f_grib_ieee ( ARG1  )

A very early method of writing grib files.

This method was never used outside of testing AFAIK. This option will be deleted in the future unless there are objections.

-grib_ieee X

X is the base filename for the output files.

Parameters
ARG1List of function arguments set by wgrib2's main() function (see ARG1). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 on success. Throws fatal_error() on failure.
