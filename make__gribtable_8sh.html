Detailed Description

Script to convert grib2 table information from the "gribtable" format to the "gribtable.dat" format.

Usage:

  • Zero arguments: "gribtable" –> "gribtable.dat"

- One argument "mytab": "mytab" --> "mytable.dat"

- Two arguments "mytab" "mytab.custom": "mytab" --> "mytab.custom"

sample "gribtab" format and corresponding "gribtable.dat" format: 0:0:0:255:7:1:7:193:4LFTX:Best (4 layer) Lifted Index:K {0,0,0,255,7,1,7,193, "4LFTX", "Best (4 layer) Lifted Index", "K"},
