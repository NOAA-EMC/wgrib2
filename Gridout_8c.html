int f_gridout ( ARG1  )

Many grib message contain grids of the following form: grid_val(NX,NY), longitude(NX,NY) and latitude(NX,NY).

Common exceptions are spectral data, thinned grids and staggered grids. If the grib message is of the first form, then you can use the -gribout option to print out i, j, latitude(i,j), longitude(i,j).

-gridout FILE

FILE is an output of the command.

This will print ((i, j, lat(i,j), lon(i,j), i=1,nx), j=1,ny) using the format "%10i,%10i, %.3f, %.3f\n" if the grid is of the form: grid_val(nx,ny), lat(nx,ny), lon(nx,ny).

FILE will be a CSV file with the latitudes and longitudes of the grid points.

Parameters
ARG1List of function arguments set by wgrib2's main() function (see ARG1). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 for success, error code otherwise
