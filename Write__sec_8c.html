int f_read_sec ( ARG2  )

Replace the section (0-8) of the current grib message with the contents from a file.

The only options that applies to the file are the -header and -no_header options. The default -header option put a 4-byte unsigned integer header and trailer around the section data. The header and trailer are the number of bytes of the section.

The -read_sec option is used to create grib files where you do not have an appropriate template.

-read_sec N file

N = section number (0-8) file = input file name

Parameters
ARG2List of function arguments set by wgrib2's main() function (see ARG2). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 on success. Throws fatal_error() on failure.

◆ f_write_sec()

int f_write_sec ( ARG2  )

Writes the current grib message section (0-8) to a file.

The only options that applies to the file are the -header, -no_header, -append, and -no_append options. The default -header option put a 4-byte unsigned integer header and trailer around the section data. The header and trailer are the number of bytes of the section.

The -write_sec option is for codes that need low-level access to the grib data.

-write_sec N file

N = section number (0-8) file = output file name

Parameters
ARG2List of function arguments set by wgrib2's main() function (see ARG2). These arguments won't be relevant to the average wgrib2 user. See the Usage section above for details about any input parameters.
Returns
0 on success. Throws fatal_error() on failure.
